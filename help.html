How to Play

Harvest & Solve is a farming RPG for Algebra I. In the planned game, solve math problems to care for crops and animals, earn gold and improve your farm. Use hints and retry problems as needed.

Saving your progress

Protect your progress!

Browser autosaves may not work reliably on school-managed Chromebooks or devices with parental controls, monitoring or filtering software like Securly. Always export your save before leaving. Keep the file somewhere safe, such as school-approved cloud storage.

How to export your save

  1. Open Continue / Save Menu.
  2. Click Export Save.
  3. Find the downloaded JSON file and keep it somewhere safe.

How to import your save

  1. Open Harvest & Solve.
  2. Click Import Save on the main menu.
  3. Choose your previously exported JSON file using the file picker.
  4. If asked, confirm replacement of the active adventure. Export your current adventure first if you want to keep it.
  5. Click Continue to resume your adventure.

Save file names

Exported filenames use charactername_mm_dd__yy.json (for example, unnamed_farmer_11_25__26.json). You may rename files and keep unlimited external backups. The game keeps one active browser save. No real name is required.

Remember: your chickens are counting on you. Back up responsibly.
